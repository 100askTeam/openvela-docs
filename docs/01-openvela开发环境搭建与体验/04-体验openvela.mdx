### 编译openvela

注意：以下是T113S3的openvela系统的编译方法，对于其他单板编译命令会有差异。

执行如下命令编译、打包：

```
cd ~/vela-opensource/vendor/allwinnertech/lichee/

source vela_env.sh

source envsetup.sh

lunch_nuttx \# 选择2

m

pack

```
其它命令：

\# 清除

```
m c

```
\# 配置

```
m menuconfig

```
\# 进入目录~/vela-opensource/vendor/allwinnertech/lichee/

```
croot

```

```
**注意**：流控（Flow Control）一定要选择none，否则你将无法在MobaXterm中向串口输入数据。

```

#### 播放声音

执行如下命令播放音乐（等它播放完毕，不要按Ctrl+C退出，否则需要重启才能再次播放）：

amixer set 6 180

amixer set 7 180

amixer set 15 7

aplay -D hw:audiocodec /data/moon.wav

#### 录制声音

执行如下命令录制声音：

amixer set 19 255

amixer set 20 255

amixer set 21 255

arecord -D hw:snddmic -r 44100 -f 16 -d 5 -c 2 /data/my.wav

然后执行如下命令播放录制的声音：

amixer set 6 180

amixer set 7 180

amixer set 15 7

aplay -D hw:audiocodec /data/my.wav

#### WIFI

执行如下命令配置、测试WIFI（最好接上天线）：

ifup wlan0

wapi mode wlan0 2

\# 100asktech 是WIFI密码,需要改成你自己的

wapi psk wlan0 "100asktech" 3

\# Programmers是WIFI AP名字,需要改成你自己的

wapi essid wlan0 "Programmers" 1

renew wlan0

\# 查看IP

ifconfig

\# ping互联网, Ctrl+C退出

ping news.qq.com
