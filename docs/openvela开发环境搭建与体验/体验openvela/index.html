体验openvela

编译openvela​

注意：以下是T113S3的openvela系统的编译方法，对于其他单板编译命令会有差异。

执行如下命令编译、打包：

cd ~/vela-opensource/vendor/allwinnertech/lichee/

source vela_env.sh

source envsetup.sh

lunch_nuttx \# 选择2

m

pack

其它命令：

# 清除

m c

# 配置

m menuconfig

# 进入目录~/vela-opensource/vendor/allwinnertech/lichee/

croot

安装烧录驱动​

**第1步：**下载并解压网盘《4_工具软件》里面的《2_全志线刷烧录驱动》，解压完成后，可以看到以下文件，

**第2步：**接上2跟USB线后，按住FEL按钮的同时短按RST按钮即可进入烧写模式，如下图所示步骤操作。

**第3步：**打开设备管理器，进入烧写模式后，设备管理器会弹出一个未知设备。

**第4步：**接下来鼠标右键点击这个未知设备，在弹出的对话框里， 点击浏览我计算机以查找驱动程序软件。

注意进入到前面解压烧录驱动的 UsbDriver/ 文件夹，然后点击确定，如下图所示。

此时，我们继续点击 下一页 按钮，这时系统就会提示安装一个驱动程序。在弹出的对话框里，我们点击始终安装此驱动程序软件等待安装完成。

最后我们可以看到，设备管理器 里面的未知设备 变成了一个 USB Device(VID_1f3a_efe8)的设备，这时就表明设备驱动已经安装成功。

烧录镜像​

**第1步：**我们需要切换到**一键刷机**窗口，如下图所示，点击**红框标号1**，在弹出的新窗口内，我们点击**红框2**浏览 找到我们前面编译出来的镜像，也可以在网盘《4_工具软件》里面的《5_开发板系统镜像》找到，选中镜像后，最后点击**红框3** “全盘擦除升级”：

**第2步：**点击完成后，**不需要理会其他任何信息**，也**不用点击立即升级**，这时 我们拿起已经连接好的开发板，**先按住 FEL** 烧写模式按键，之后**按一下 RST**复位键，就可以自动进入烧写模式并开始烧写。

烧写时会提示烧写进度条，烧写完成后 开发板会自己重启，并询问是否要升级，如下选择“N”即可：

播放声音​

执行如下命令播放音乐（等它播放完毕，不要按Ctrl+C退出，否则需要重启才能再次播放）：

amixer set 6 180

amixer set 7 180

amixer set 15 7

aplay -D hw:audiocodec /data/moon.wav

录制声音​

执行如下命令录制声音：

amixer set 19 255

amixer set 20 255

amixer set 21 255

arecord -D hw:snddmic -r 44100 -f 16 -d 5 -c 2 /data/my.wav

然后执行如下命令播放录制的声音：

amixer set 6 180

amixer set 7 180

amixer set 15 7

aplay -D hw:audiocodec /data/my.wav

WIFI​

执行如下命令配置、测试WIFI（最好接上天线）：

ifup wlan0

wapi mode wlan0 2

# 100asktech 是WIFI密码,需要改成你自己的

wapi psk wlan0 "100asktech" 3

# Programmers是WIFI AP名字,需要改成你自己的

wapi essid wlan0 "Programmers" 1

renew wlan0

# 查看IP

ifconfig

# ping互联网, Ctrl+C退出

ping news.qq.com
