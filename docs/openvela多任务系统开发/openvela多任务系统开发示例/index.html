openvela多任务系统开发示例

项目规划​

本节将基于多任务系统，创建多个进程：功能相对独立的程序创建为不同的进程。比如音乐播放器、聊天软件，这就应该创建为2个进程。进程里面可以创建多个线程，比如音乐播放器里可以创建出MP3解码线程、声音播放线程、GUI线程。

面向openvela初学者，本章节创建的任务、线程不会很复杂，目的在于掌握进程、线程的划分、创建。由于我们还没学到线程间的通信、互斥、同步，所以使用全局变量进行交互。

音乐任务功能如下：

  • 控制线程：接收用户输入，发送“0~9”的数字给“播放线程”

  • 播放线程：根据收到的信息播放“0~9”的声音

灯光任务功能为：根据按键控制LED，按键被按下则点亮LED并维持50 0ms。

# ubuntu

ffmpeg -i 0.wav -bitexact -ac 1 -sample_fmt s16 0_2.wav

音乐任务编程​

本节源码位于如下目录：

3-3-2B_音乐任务编程\music

我们可以手工执行命令“aplay xxx.wav”来播放声音，想自动化运行就需要编程，有两种方法：

  • 修改aplay的代码，添加我们的功能

  • 在我们的代码里调用aplay程序

本课程的重点在于openvela本身，我们不打算深入研究aplay的代码，所以我们使用第2种办法。声卡的使用是一个专门的课题，既然有现成的命令给我们使用，可以加快开发效率。

可以使用posix_spawn、task_spawn、task_create三个函数创建进程以调用aplay：

  • aplay命令没有真正的“可执行文件”，这是一个“内嵌的文件”

  • aplay命令所对应函数为“aplay_main”：

aplay.c里有main函数，在编译aplay.c时main被当做宏替换为aplay_main。

  • aplay命令的源码位于：

vendor/allwinnertech/chips/r528/drivers/rtos-hal/hal/test/sound/aplay.c

下面使用3种方法创建进程调用aplay。

① 使用task_create，代码如下：

char \* argv\[2\] = {"/data/0.wav", NULL};

if (0 \> task_create("aplay", 100, 2048, aplay_main, argv))

printf("task_create err\n");

else

printf("task_create ok\n");

② 使用task_spawn，代码如下：

char \* argv\[2\] = {"/data/0.wav", NULL};

if (0 \> task_spawn("aplay", aplay_main, NULL, NULL, argv, NULL))

printf("task_spawn err\n");

else

printf("task_spawn ok\n");

③ 使用posix_spawn，代码如下（注意：使用posix_spawn时argv会原原本本传给main函数，而使用前面2种方法时argv传给main函数后变成argv[1]、argv[2]……）：

char \* argv\[3\] = {"aplay", "/data/0.wav", NULL};

if (0 != posix_spawn(&pid, "aplay", NULL, NULL, argv, NULL))

printf("posix_spawn err\n");

else

printf("posix_spawn ok\n");

openvela的GPIO API接口​

参考代码：apps/examples/gpio/gpio_main.c

APP如何操作GPIO？接口函数为open/ioctl。

首先使用open函数打开设备节点：

#include &lt;sys/types.h&gt;

#include &lt;sys/stat.h&gt;

#include &lt;fcntl.h&gt;

int open(const char \*pathname, int flags);

int open(const char \*pathname, int flags, mode_t mode);

然后使用ioctl获取、设置引脚方向，它的参数个数是可变的，如下：

#include &lt;sys/ioctl.h&gt;

#include &lt;nuttx/ioexpander/gpio.h&gt;

int ioctl (int fd, int cmd, ...);

比如获得gpio引脚类型：

enum gpio_pintype_e pintype;

int ret;

/* Command: GPIOC_PINTYPE

* Description: Return the GPIO pin type.

* Argument: A pointer to an instance of type enum gpio_pintype_e

*/

ret = ioctl(fd, GPIOC_PINTYPE, (unsigned long)((uintptr_t)&pintype));

if (ret == -1)

/* error */

设置gpio的引脚类型：

enum gpio_pintype_e newpintype = GPIO_OUTPUT_PIN;

int ret;

/* Command: GPIOC_SETPINTYPE

* Description: Set the GPIO pin type.

* Argument: The enum gpio_pintype_e type.

*/

ret = ioctl(fd, GPIOC_SETPINTYPE, (unsigned long) newpintype);

if (ret == -1)

/* error */

最后，可以读、写引脚。

写gpio引脚让它输出高低电平：

bool outvalue = true;

int ret;

/* Command: GPIOC_WRITE

* Description: Set the value of an output GPIO

* Argument: flase=output a low value; true=output a high value

*/

ret = ioctl(fd, GPIOC_WRITE, (unsigned long)outvalue);

if (ret == -1)

/* error */

读gpio引脚获得引脚电平：

bool invalue;

int ret;

/* Command: GPIOC_READ

* Description: Read the value of an input or output GPIO

* Argument: A pointer to an bool value to receive the result:

* false=low value; true=high value.

*/

ret = ioctl(fd, GPIOC_READ, (unsigned long)((uintptr_t)&invalue));

if (ret == -1)

/* error */
